# 文档归档

本目录只保存仍有迁移、审计或历史解释价值，但不再约束当前实现的文档。

## 区域

- `pre-product-redesign/`：学习闭环产品重构前的架构、能力升级和评测专项。
- `project-history/`：已被当前 tracker、runbook 或规格替代的项目级历史记录。

## 使用规则

- 当前实现先读 [`../specs/README.md`](../specs/README.md)。
- 当前产品方向先读 [`../product-architecture.md`](../product-architecture.md)。
- 当前优先级和问题分别读 [`../../ROADMAP.md`](../../ROADMAP.md) 与
  [`../../issue.md`](../../issue.md)。
- 归档内容只有 historical authority；路径、命令、状态和基线可能已经过期。
- 归档文件不得重新成为实现契约，除非其内容被审查后重新沉淀到当前规格。
