# Ideas

## Agent memory and learning model

Date: 2026-06-06

一个 agent 的能力可以从“记忆”的角度理解：

- 模型本身内化的知识和技能，可以看作一种模糊记忆。它覆盖面广，但边界不稳定，调用时依赖上下文、提示和模型自身的泛化能力。
- 工程化设计出来的记忆，可以看作经过反复练习、验证和沉淀后的知识技能。它更接近可审计、可迁移、可升级的能力资产。
- 这些记忆不是静态的：它们可以被升级、复用、迁移，也可以在新的任务和环境中继续被校正。
- agent 的学习过程，本质上可以理解为构建、验证、组织和迁移这些记忆的过程。
- 在具体实践中，应参考人的行为逻辑和学习行为：观察任务、形成经验、反复练习、验证反馈、抽象规律，再把稳定规律沉淀为可复用记忆。

这个思路可以作为后续设计 agent memory、skill lifecycle、workflow 沉淀、评测闭环和能力迁移机制的概念基础。
