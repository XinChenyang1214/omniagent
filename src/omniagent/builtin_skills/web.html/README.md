# builtin.web.html

HTML parsing for already-fetched or local HTML evidence.

Examples:

```json
{"action": "extract", "path": "artifacts/page.html"}
```

```json
{"action": "links", "text": "<a href=\"/docs\">Docs</a>"}
```

```json
{"action": "report", "path": "artifacts/page.html", "output_path": "reports/page.md"}
```
